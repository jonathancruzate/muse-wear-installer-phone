# Muse Wear Installer Phone v1.0.2 — build record (2026-11-16)

## What v1.0.2 is

The transport-migration release: the app gains a transport-directive
handler (Device Assistance v1.9 semantics), so the Worker can move
it from the legacy pair (base `/mode-sync` + legacy shared secret)
to `https://jonathancruzate.com/bridge` + the wear lane secret with
no on-device edit — closing the last wear-lane blocker in
BRIDGE-MIGRATION-2026-11-13.md.

- `TransportDirective.java` (new): the pure decision class —
  INVALID / SAME / NEEDS_PROBE / SWITCH / STAY_PROBE_FAILED.
  Well-formed = https (or tailnet http://100.) base + secret ≥ 16
  chars. A same-base/new-secret directive is a rotation: it probes
  and switches like any other change; only an identical pair is
  SAME.
- `WorkerClient.java`: poll, command-result, and report responses
  are all scanned for a `transport` directive. On a well-formed,
  different pair the client PROBES first — a harmless authenticated
  read (GET the lane's stored report on the candidate base with the
  candidate secret; 200 + parseable JSON) — and persists the new
  pair only on probe success, keeping the previous pair plus a
  24 h probation window. `maybeRevertTransport` (called by
  CommandService when a cycle fetched nothing AND its report
  failed) probes the previous pair during probation and reverts on
  success. Every report now carries a `transport` object —
  {base (host+path only, never the secret), state, at} — which the
  Worker whitelists into `wearbridge:report`, so the migration is
  observable server-side.
- `Store.java`: transport keys (prev pair, switched-at, probation-
  until, last outcome + its timestamp), same key names as DA.
- User-Agent bumped to `MuseWearInstallerPhone/1.0.2`.

Worker side (already deployed 2026-11-16, before this build): while
the KV flag `wearbridge:transport-directive` is `armed`, every
wear-lane poll / report / result response carries
`transport: {base: https://jonathancruzate.com/bridge, secret:
<wear lane secret, read from the BRIDGE_SECRET_WEAR binding at
request time>}`. Disarmed by deleting the flag. Backup:
`worker.js.bak-20261116-pre-wear-transport`; 9 bindings preserved.
